# Ciclo de experimentos (proposta)

`ideia -> experimento_isolado -> medido -> revisado -> aprovado_editor -> promovido`, com ramo `descartado` e `bloqueado` acompanhado de justificativa.

Promoção para outros repositórios exige testes de integração, changelog, plano de rollback e autorização do editor. Nenhuma execução de agente, gasto API, instalação, merge ou deploy é inferida a partir de `medido` ou `revisado`.

Este arquivo é contrato prospectivo, não substitui protocolo MZ-MSG.
