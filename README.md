# MEGAZORD-LAB

Laboratório **público** de testes sintéticos da comunicação multiagente.

- Não contém dados pessoais, materiais escolares, PDFs privados ou chaves de API.
- Não copia conteúdos de `megazord-ia` (privado).
- Os testes são **offline**, sem chamadas a modelos externos e sem dependências de terceiros.
- Nenhum workflow deste laboratório aprova merges ou publica projetos.
- Controle de gastos do GitHub deve permanecer ativo; não alterar configurações de faturamento para executar testes.
